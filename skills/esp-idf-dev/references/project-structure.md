## Project Layout

**Minimal project:**
```
my_project/
├── CMakeLists.txt          # Project-level CMake (required)
├── main/
│   ├── CMakeLists.txt      # Main component CMake (required)
│   └── main.c              # Entry point with app_main()
├── sdkconfig               # Generated by menuconfig (gitignore the file itself)
├── sdkconfig.defaults      # Committed defaults (checked into git)
└── partitions.csv          # Custom partition table (optional)
```

**Production project with custom components:**
```
my_project/
├── CMakeLists.txt
├── sdkconfig.defaults
├── sdkconfig.defaults.esp32s3   # Target-specific overrides (applied automatically)
├── partitions.csv
├── main/
│   ├── CMakeLists.txt
│   ├── main.c
│   └── Kconfig.projbuild   # Adds options to menuconfig (optional)
├── components/
│   ├── sensors/
│   │   ├── CMakeLists.txt
│   │   ├── include/
│   │   │   └── sensors.h
│   │   ├── sensors.c
│   │   └── Kconfig          # Component-specific config (optional)
│   └── display/
│       ├── CMakeLists.txt
│       ├── include/
│       │   └── display.h
│       └── display.c
└── managed_components/      # Auto-downloaded; gitignore this
    └── espressif__led_strip/
```

## CMakeLists Templates

**Project root CMakeLists.txt:**
```cmake
cmake_minimum_required(VERSION 3.16)

# Optional: add extra component directories
# set(EXTRA_COMPONENT_DIRS "/path/to/shared/components")

include($ENV{IDF_PATH}/tools/cmake/project.cmake)
project(my_project)
```

**main/CMakeLists.txt (simple):**
```cmake
idf_component_register(
    SRCS "main.c"
    INCLUDE_DIRS "."
    REQUIRES esp_wifi esp_event esp_netif nvs_flash mqtt esp_driver_i2c
)
```

**main/CMakeLists.txt (with multiple source files):**
```cmake
idf_component_register(
    SRCS "main.c" "wifi.c" "mqtt_handler.c"
    INCLUDE_DIRS "." "include"
    REQUIRES esp_wifi mqtt nvs_flash
    PRIV_REQUIRES esp_timer
)
```

**REQUIRES vs PRIV_REQUIRES:**
- `REQUIRES` — Public dependency. Other components that depend on YOU will also get access to these headers. Use when your public headers (#include in .h files) reference types from the dependency.
- `PRIV_REQUIRES` — Private dependency. Only your .c files need it. Use for implementation details.
- Rule of thumb: if the dependency's types appear in your `.h` files → `REQUIRES`. If only in `.c` files → `PRIV_REQUIRES`.

**Custom component CMakeLists.txt:**
```cmake
# components/sensors/CMakeLists.txt
idf_component_register(
    SRCS "sensors.c"
    INCLUDE_DIRS "include"
    REQUIRES esp_driver_i2c
    PRIV_REQUIRES esp_timer
)
```

**Embedding files (certificates, web assets):**
```cmake
idf_component_register(
    SRCS "main.c"
    INCLUDE_DIRS "."
    EMBED_TXTFILES "server_cert.pem"
    EMBED_FILES "index_html.gz"
)
```
Access in code:
```c
extern const uint8_t server_cert_pem_start[] asm("_binary_server_cert_pem_start");
extern const uint8_t server_cert_pem_end[] asm("_binary_server_cert_pem_end");

extern const uint8_t index_html_gz_start[] asm("_binary_index_html_gz_start");
extern const uint8_t index_html_gz_end[] asm("_binary_index_html_gz_end");
```

## Multi-Component Project

Break your project into reusable components when it grows beyond ~500 lines in main:

```
components/
├── sensor_hub/           # Manages all sensor I2C communication
│   ├── CMakeLists.txt
│   ├── include/sensor_hub.h
│   └── sensor_hub.c
├── control/              # PID loops, relay/actuator logic
│   ├── CMakeLists.txt
│   ├── include/control.h
│   └── control.c
└── web_server/           # HTTP dashboard
    ├── CMakeLists.txt
    ├── include/web_server.h
    ├── web_server.c
    └── www/              # Embedded web assets
        └── index.html
```

Components discover each other by name. A component in `components/control/` that needs sensor data:
```cmake
# components/control/CMakeLists.txt
idf_component_register(
    SRCS "control.c"
    INCLUDE_DIRS "include"
    REQUIRES sensor_hub    # references sensor_hub.h in control.h
)
```

## Managed Components

Use Espressif's component registry for third-party libraries. Creates `idf_component.yml` in your main or component directory.

**Add a dependency:**
```bash
cd main
idf.py add-dependency "espressif/led_strip^3.0.0"
# Creates/updates main/idf_component.yml
```

**main/idf_component.yml:**
```yaml
dependencies:
  espressif/led_strip: "^3.0.0"
  espressif/button: "^3.2.0"
  # Version syntax: ^3.0.0 (compatible), ~3.0.0 (patch only), >=3.0.0
```

**Common managed components:**
| Component | Use Case |
|-----------|----------|
| `espressif/led_strip` | WS2812/SK6812 addressable LEDs via RMT |
| `espressif/button` | GPIO button with debounce, long-press |
| `espressif/esp_lcd_*` | Display drivers (SSD1306, ST7789, etc.) |
| `espressif/mqtt` | MQTT client (will be required in v6.0+) |
| `espressif/esp_tinyusb` | USB device support |
| `espressif/cbor` | CBOR encoding/decoding |

After adding, `idf.py build` automatically downloads to `managed_components/`. Add this directory to `.gitignore`.

## Partition Tables

**Default partition table** (4MB flash, no OTA):
```
# Name,   Type, SubType, Offset,  Size, Flags
nvs,      data, nvs,     0x9000,  0x6000,
phy_init, data, phy,     0xf000,  0x1000,
factory,  app,  factory, 0x10000, 1M,
```

**Custom partition table with OTA** (4MB flash):
```csv
# Name,   Type, SubType,  Offset,   Size,    Flags
nvs,      data, nvs,      0x9000,   0x4000,
otadata,  data, ota,      0xd000,   0x2000,
phy_init, data, phy,      0xf000,   0x1000,
ota_0,    app,  ota_0,    0x10000,  0x1C0000,
ota_1,    app,  ota_1,    0x1D0000, 0x1C0000,
storage,  data, spiffs,   0x390000, 0x70000,
```

**Enable custom partition table in menuconfig:**
- `Partition Table → Partition Table → Custom partition table CSV`
- `Partition Table → Custom partition CSV file → partitions.csv`

Or in `sdkconfig.defaults`:
```
CONFIG_PARTITION_TABLE_CUSTOM=y
CONFIG_PARTITION_TABLE_CUSTOM_FILENAME="partitions.csv"
```

**Sizes must be aligned to 0x1000 (4KB).** Total must not exceed flash size. App partitions should be at least 0x100000 (1MB) for most real applications.

## OTA Updates

**HTTPS OTA (simplest approach):**
```c
#include "esp_ota_ops.h"
#include "esp_https_ota.h"
```
```cmake
REQUIRES esp_https_ota app_update
```

```c
void ota_task(void *param)
{
    esp_http_client_config_t config = {
        .url = "https://server.com/firmware.bin",
        .cert_pem = (char *)server_cert_pem_start,
    };
    esp_https_ota_config_t ota_config = {
        .http_config = &config,
    };

    ESP_LOGI(TAG, "Starting OTA update...");
    esp_err_t ret = esp_https_ota(&ota_config);
    if (ret == ESP_OK) {
        ESP_LOGI(TAG, "OTA succeeded, rebooting...");
        esp_restart();
    } else {
        ESP_LOGE(TAG, "OTA failed: %s", esp_err_to_name(ret));
    }
    vTaskDelete(NULL);
}
```

**Rollback protection:**
Requires `CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y` in sdkconfig (or sdkconfig.defaults).
```c
// After OTA boot, mark firmware as valid (otherwise rolls back after reboot)
const esp_partition_t *running = esp_ota_get_running_partition();
esp_ota_img_states_t ota_state;
if (esp_ota_get_state_partition(running, &ota_state) == ESP_OK) {
    if (ota_state == ESP_OTA_IMG_PENDING_VERIFY) {
        // Run self-test, then:
        esp_ota_mark_app_valid_cancel_rollback();
    }
}
```

## Menuconfig Key Settings

Access via `idf.py menuconfig`. Most important settings by category:

**Flash & Partition:**
- `Serial flasher config → Flash size` — Must match your board (usually 4MB or 16MB)
- `Partition Table → Partition Table` — Single factory / Two OTA / Custom CSV

**WiFi:**
- `Component config → Wi-Fi → WiFi Task Core ID` — Pin WiFi task to core
- `Component config → Wi-Fi → Max number of WiFi static RX buffers` — Increase for throughput

**FreeRTOS:**
- `Component config → FreeRTOS → Kernel → configTICK_RATE_HZ` — Default 100 (10ms tick). Increase for finer timing.
- `Component config → FreeRTOS → Port → Tick timer source` — Use `esp_timer` for better power mgmt
- `Component config → FreeRTOS → Kernel → Run FreeRTOS only on first core` — Single-core mode

**Logging:**
- `Component config → Log → Default log verbosity` — Set to `Info` for production, `Debug` for dev
- `Component config → Log → Maximum log verbosity compiled` — Set lower to strip debug logs from binary

**Performance:**
- `Compiler options → Optimization Level` — `Performance (-O2)` for production
- `Component config → ESP System Settings → CPU frequency` — 240MHz max, 80MHz for low power

**Using `sdkconfig.defaults` instead of menuconfig:**
Commit `sdkconfig.defaults` to git (not `sdkconfig`). Put your overrides here:
```
# sdkconfig.defaults
CONFIG_ESPTOOLPY_FLASHSIZE_4MB=y
CONFIG_PARTITION_TABLE_CUSTOM=y
CONFIG_PARTITION_TABLE_CUSTOM_FILENAME="partitions.csv"
CONFIG_ESP_WIFI_SSID="DefaultSSID"
CONFIG_FREERTOS_HZ=1000
CONFIG_LOG_DEFAULT_LEVEL_INFO=y
CONFIG_COMPILER_OPTIMIZATION_PERF=y
CONFIG_ESP_DEFAULT_CPU_FREQ_MHZ_240=y
CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y
# Uncomment if porting older code to v5.4+ and hitting new GCC 14 warnings:
# CONFIG_COMPILER_DISABLE_GCC14_WARNINGS=y
```
Then `idf.py fullclean && idf.py build` to regenerate `sdkconfig` from defaults.

**Target-specific overrides:**
Create `sdkconfig.defaults.esp32s3` alongside `sdkconfig.defaults`. It's applied automatically when the target is ESP32-S3.
